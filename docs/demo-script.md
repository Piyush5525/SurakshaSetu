# Demo script (7 minutes)

**Setup (before the audience).** Terminal 1: `npm run dev`. Terminal 2: `npm run demo:cameras` (sample videos through the real pipeline; wait about 40 s for the first frames). Print stickers first: **Admin → QR Management → Print sheet**; set the address to your Wi-Fi IP and scan with a phone on the same network. Open the Control Centre (`admin` / `demo1234`) on the big screen, a phone-size browser for the worker views, and `/board` on a second screen. Alerts are **simulated** (the banner says so) unless `DEMO_MODE=false`; say so.

## If something fails

- Cameras show "No video received": run `npm run demo:cameras` and wait about 40 s; the worker needs Python with `3-auto-cv/requirements.txt`.
- Phone cannot open the sticker: set your PC's Wi-Fi address in **QR Management** and reprint; same network; allow ports 5174 and 8000 in the Windows firewall.
- A feature needs real alerts: set `DEMO_MODE=false` and the Telegram/OmniDimension variables in `.env`, restart, then **Settings → Send test Telegram** first.

## Verification before presenting

`npm run lint && npm run typecheck && npm test`, `cd 3-auto-cv && python -m pytest`, and `npm run e2e` (with `npm run dev` running).
